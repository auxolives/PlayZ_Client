# PlayZ_Client

Client-side PlayZ mod sources. Packed as PBOs and loaded with `-mod=` on **both** the game client and the dedicated server.

## Sub-mods

| Folder | Role |
|--------|------|
| `PlayZ_Core` | Core gameplay tweaks (anti-combat logout, consume/mouth block, backpack UI, crafting, configs) |

Each folder is one addon (`config.cpp` → own PBO).
